# CyberVisionAg - Evaluation Results

## Overview
This directory contains evaluation results from the CyberVisionAg agentic plant disease classification pipeline. Each result represents a model's inference on a test image with reasoning traces and confidence scores.

**Last Updated:** 2026-05-03

## Directory Structure

```
results/open_agentic/
├── [Crop_Name]/
│   ├── [source_type]/  (internet, local, etc.)
│   │   ├── [model]/    (sonnet, opus, etc.)
│   │   │   ├── k0/     (few-shot k values)
│   │   │   │   ├── [disease]__[image_id].json
│   │   │   │   └── ...
│   │   │   ├── k1/
│   │   │   └── k4/
│   │   └── ...
│   └── ...
├── results_manifest.json    (structured results metadata)
├── RESULTS_SUMMARY.txt      (human-readable summary)
└── README.md                (this file)
```

## Results Structure

### Result File Format
Each `.json` file contains:
```json
{
  "image_id": "string",
  "disease_name": "string",
  "model": "string",
  "confidence": number,
  "reasoning": "string",
  "is_correct": boolean
}
```

### Directory Naming Convention
- **Crop:** Crop being evaluated (Banana, Tomato, etc.)
- **Source Type:** Knowledge base source
  - `internet` - Web-based symptom information
  - `local` - Local knowledge base
  - `none` - No external knowledge (baseline)
- **Model:** Claude model variant
  - `sonnet` - Claude Sonnet
  - `opus` - Claude Opus
  - `haiku` - Claude Haiku
- **K-Value:** Few-shot learning parameter
  - `k0` - Zero-shot
  - `k1` - One-shot
  - `k4` - Four-shot

## Analysis Scripts

### Generate Performance Metrics
```bash
python open_agentic/generate_tables.py
```
Produces confusion matrices and accuracy metrics across all evaluations.

### Plot Results
```bash
python open_agentic/generate_figures.py
```
Generates visualization of results across different configurations.

### Run New Evaluations
```bash
# Single crop evaluation
python open_agentic/eval.py --crops Tomato_Diseases

# Full dataset evaluation with sweeps
./open_agentic/run_sweeps.sh
```

## Interpreting Results

### Accuracy Metrics
- Look at `results_manifest.json` for structured counts
- Use `generate_tables.py` for detailed confusion matrices
- Compare across models, k-values, and source types

### Few-Shot Learning Impact
- Compare `k0` (zero-shot) vs `k1` vs `k4` to measure few-shot improvement
- Typical pattern: accuracy increases with more examples (k0 < k1 < k4)

### Source Type Comparison
- `none` - Baseline without external knowledge
- `local` - With local knowledge base
- `internet` - With web-sourced information
- Measure improvement from external knowledge integration

## Integration with Pipeline

Results are automatically generated by:
1. **eval.py** - Main evaluation script
2. **run_sweeps.sh** - Batch evaluation runner
3. **run_model_k_sweep.sh** - Few-shot parameter sweep

Results are used by:
1. **generate_tables.py** - Performance metrics
2. **generate_figures.py** - Visualizations
3. **trace_to_tex.py** - Research paper generation
